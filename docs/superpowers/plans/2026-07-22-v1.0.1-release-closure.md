# v1.0.1 发布收口实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 P0 安全与稳定性改造成版本、文档和验证证据一致的 `v1.0.1` 可发布变更集，不执行远端写入。

**Architecture:** 先扩展根 Validator 冻结公开版本声明，再更新版本和文档；随后通过现有 fixture、CLI、Plugin Creator 和隔离 Codex 配置验证发布产物。远端状态只读核验，无法证明的发布动作明确留给维护者。

**Tech Stack:** Node.js 20+、ESM、`node:test`、Git、Codex Plugin CLI、零第三方依赖。
