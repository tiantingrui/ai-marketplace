## v1.0.1：安全与稳定性

状态：待发布。PR #1 仍为草稿，目标提交六组 CI 已通过；正式评审、合并、标签、远端安装冒烟和 GitHub Release 尚未执行。

- 安全读取已完成：Git 内容在读取前执行敏感路径过滤，普通文本与配置读取执行文件类型检查、符号链接拒绝、真实路径范围检查及文件身份复核；插件声明路径独立执行词法范围、文件类型、符号链接拒绝和 `realpath` 信任根检查。
- 严格配置已完成：`.ai-marketplace.json` 的嵌套字段、枚举、路径、重复规则 ID 和引用关系均执行严格校验。
- 六份描述性 Schema、五类规则注册表和多本地插件动态发现基础已完成。
- CI 已配置 Ubuntu、macOS 与 Node.js 20、22、24 矩阵；目标发布提交仍需在远端发布前复核。
- 本地完整验证和隔离验证的状态与证据统一记录在 [`docs/releases/2026-07-22-v1.0.1-validation.md`](releases/2026-07-22-v1.0.1-validation.md)。

发布前验收条件：支持环境完成远端复核；命中敏感路径规则的文件、符号链接和仓库外文件均不会进入分析上下文；现有 `schemaVersion: 1.0` 输出保持兼容；本地完整与隔离验证按验收记录完成。

## v1.1.0：接入体验与分析准确度

- 在已有描述性 Schema 基础上提供 `config validate`、`config explain` 和配置初始化流程，并评估引入标准 Schema 执行器。
- 从 npm、pnpm 和 Yarn workspace 声明发现应用与共享包，不再依赖固定的 `apps/*`、`packages/*` 布局。
- 覆盖重命名、嵌套 workspace、共享包消费者和相关测试范围。
- 在已有规则、影响和评审输出 Schema 基础上强化兼容性校验，并评估 SARIF 输出用于 CI 集成。
- 明确真实依赖、配置关系和关键词推断的证据等级。

验收条件：至少三个不同布局的脱敏仓库通过前向验证；旧版配置继续有效；新增输出字段保持向后兼容。

## v1.2.0：可量化质量闭环

- 扩展 React、Next.js、通用 TypeScript 和多种 monorepo 布局的黄金与负向用例。
- 记录确定性规则误报、语义评审准确度、纯格式噪声和运行耗时。
- 增加大型 diff、二进制、删除、重命名、截断和异常 Git 状态测试。
- 为每次发布保留可比较的前向评测报告。

建议质量目标：确定性规则误报率低于 2%；高风险黄金用例检出率不低于 90%；纯格式变更零实质评论；5,000 行变更在常规开发机上五秒内完成证据收集。

## v1.3.0：Marketplace 扩展

- 在已支持多本地插件遍历的基础上，扩展 Git、npm、remote source 和更完整的可选能力组合。
- 建立跨插件通用的版本一致性、文档、权限和安装产物策略，不再依赖 `frontend-engineering-standard` 专属门禁。
- 提供贡献模板与最小插件示例。
- 根据真实使用反馈选择第二插件，候选方向包括仓库接入、测试影响或发布风险检查。

涉及网络、代码托管评论、需求系统或其他外部写入的能力保持独立插件，并要求最小权限、人工确认和审计记录。

## v2.0.0：不兼容契约与外部集成

只有在配置模型、输出契约、权限边界或安装方式必须发生不兼容变化时才进入主版本升级。升级前必须提供迁移工具、兼容说明、回退版本和独立安全评审。

## 持续指标

- 支持环境与干净标签安装成功率。
- 自动测试、Validator 和隔离前向评测结果。
- 确定性规则的误报与漏报样本。
- 模型评审被采纳、降级为问题或判定无证据的比例。
- 分析耗时、diff 截断率和异常退出率。
