## 兼容性

- 支持 Node.js `>=20`；CI 定义覆盖 Node.js 20、22、24。
- 项目配置与现有报告继续使用 `schemaVersion: 1.0`。
- `check-project-rules`、`analyze-change-impact`、`review-pull-request` 三个 Skill 及其 `rules`、`impact`、`review-context` CLI 入口保持兼容；成功、分析失败和用法错误继续使用既有退出码 `0`、`1`、`2`。
- 本次收口零新增依赖；根包继续不声明第三方 `dependencies` 或 `devDependencies`。
