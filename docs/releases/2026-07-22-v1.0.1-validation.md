# v1.0.1 发布验收记录

## 范围

本记录跟踪 `v1.0.1` 安全与稳定性补丁的发布前验收。范围限于已经收口的安全读取、严格配置、机器契约、规则治理和本地 Marketplace 动态发现基础，以及本轮仍需执行的本地与隔离验证；不新增运行时能力、第三方依赖或远端写入。

`config validate`、`config explain`、配置初始化和基于 npm、pnpm、Yarn workspace 声明的动态发现仍属于 `v1.1.0`，不纳入本次发布。

## 兼容性

- 支持 Node.js `>=20`；CI 定义覆盖 Node.js 20、22、24。
- 项目配置与现有报告继续使用 `schemaVersion: 1.0`。
- `check-project-rules`、`analyze-change-impact`、`review-pull-request` 三个 Skill 及其 `rules`、`impact`、`review-context` CLI 入口保持兼容；成功、分析失败和用法错误继续使用既有退出码 `0`、`1`、`2`。
- 本次收口零新增依赖；根包继续不声明第三方 `dependencies` 或 `devDependencies`。

## 远端发布边界

本记录完成只代表本地发布准备和证据记录达到相应状态。创建或移动 `v1.0.1` 标签、推送分支或标签、从远端标签安装以及创建 GitHub Release 均需维护者单独明确授权；本轮不执行或暗示这些远端动作已经完成。
