# AI Marketplace 1.0.0 公开发布验收计划

本计划在公开版代码修改前创建。公开发行采用 Apache License 2.0。

## 发布身份

- 仓库与产品名称：`ai-marketplace`。
- Marketplace 标识：`ai-marketplace`。
- 首发插件标识：`frontend-engineering-standard`。
- 安装选择器：`frontend-engineering-standard@ai-marketplace`。
- 公开稳定标签：`v1.0.0`。

## 去品牌要求

- 当前版本文件中不得出现原项目、公司包命名、内部应用名、内部域名或个人绝对路径。
- 插件描述、Skill、脚本、测试、样例和文档全部使用通用工程术语。
- 公开 `v1.0.0` 使用干净根提交，不携带早期项目专属历史。

## 通用能力要求

### 项目规则自检

- 默认提供适用于常见 TypeScript/React 仓库的安全规则。
- 项目专属规则通过目标仓库根目录 `.ai-marketplace.json` 配置。
- 支持路径范围、禁止 import、CSS 单位、精确计算库和共享工具目录配置。
- 没有配置时不得假设特定应用名、品牌名、包名或业务工具。

### 需求影响分析

- 从 workspace package.json 自动发现应用和共享包。
- 配置可声明等价应用组、共享工具包和高风险关键词。
- 没有配置时只输出有路径、依赖或通用关键词证据的结论。

### PR 智能评审

- 继续复用规则报告、影响报告、敏感文件过滤和最多 8 条发现契约。
- 不绑定特定金额类、路由封装或品牌结构。
- 对纯格式变化保持零实质评论。

## 公开仓库要求

- README 使用公共定位与通用示例。
- 提供配置参考、最小示例、贡献规范、行为准则、安全策略和发布流程。
- 安装说明固定到 `v1.0.0`。
- CODEOWNERS、PR 模板和只读 CI 保持有效。
- 敏感信息扫描不得发现凭据、内部域名、个人绝对路径或非公开分发说明。
- `LICENSE`、根包与插件清单统一声明 Apache-2.0。

## 验收门禁

- `node scripts/validate-all.mjs` 全部通过。
- Plugin Validator 通过。
- 三个 Skill Validator 全部通过。
- 当前版本执行去品牌扫描结果为 0。
- 当前版本执行敏感信息扫描结果为 0。
- 至少两个不相关的通用示例仓库完成前向验证。
- 本机 Marketplace 与插件迁移为新的 1.0.0 身份并显示 installed、enabled。
- `v1.0.0` 标签指向最终验收提交。

## 外部发布门禁

- Apache-2.0 许可证已确认。
- 干净公共历史策略已确认。
- GitHub 仓库切换为 Public。
- `main` 与 `v1.0.0` 推送完成。
- 从远端标签完成一次干净安装。

## 结果

- 公共身份、通用配置引擎、插件内执行脚本和公开文档已完成。
- 本地结构校验与 14 个自动测试通过。
- 官方 Plugin Validator 与三个 Skill Validator 通过。
- 项目标识、个人绝对路径和凭据扫描结果为 0。
- 金额风险与纯格式两个隔离前向用例通过；发现的纯空白测试噪声已修复并回归验证。
- Apache-2.0 与干净公共历史已确认；远端安全推送和标签发布仍待完成。
